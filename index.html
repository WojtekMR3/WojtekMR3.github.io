How I work

I run AI agents
like a small team

I don't write code by hand. I own everything around it: the spec, the review, the testing and the release.

  1. 01

    Spec

    Write down what "done" looks like before any code: inputs, edge cases, what the user sees.

    pdf-insight: the output is a Zod-validated JSON contract shared by the browser and the server.

  2. 02

    Agent

    Claude Code, Codex or Grok write the code in small steps. I review every diff and keep project rules in CLAUDE.md / AGENTS.md.

    AgentDeck: I built my own app to run several agent sessions side by side.

  3. 03

    Test for real

    Unit tests first, then the real thing: a real browser, a real app, real hardware.

    Volume Pro: a test harness drives Chrome with the extension loaded on live sites.

  4. 04

    Ship

    Releases, store submissions and live demos, then iterate on what users report.

    SunsetMonitor on GitHub Releases, Volume Pro on the Chrome Web Store.
